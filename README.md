# Portfolio — Isabella Anton

Portfólio pessoal convertido de HTML puro para um projeto React (Vite).

## Como rodar localmente

npm install
npm run dev

Abre em http://localhost:5173

## Como gerar a versão de produção

npm run build

Os arquivos finais ficam na pasta dist/, prontos pra subir em qualquer serviço de hospedagem (Vercel, Netlify, GitHub Pages, etc).
