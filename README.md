## Projetos em destaque

- **ZeroDesperdicio:** aplicativo para conectar doadores e receptores de alimentos, desenvolvido com React e Firebase.
- **Unifor Hunt:** experiência acadêmica com geolocalização e gamificação.
- **RallyCourt.io:** simulador de tênis interativo com inteligência artificial.
- **GridWave:** drum machine em português do Brasil, feita com JavaScript moderno e Web Audio API. Permite montar padrões, ajustar o mixer e gravar ideias sem instalar dependências.

## Executar localmente

É necessário ter o [Node.js](https://nodejs.org/) instalado. No terminal, entre na pasta do projeto e execute:

```bash
npm install
npm run dev
```

Abra no navegador o endereço informado pelo Vite, normalmente `http://localhost:5173/`.

## Gerar a versão de produção

```bash
npm run build
```

O Vite gera os arquivos prontos para publicação na pasta `dist/`. Para visualizar essa versão localmente:

```bash
npm run preview
```
