# Portfolio — Isabella Anton

Portfólio pessoal convertido de HTML puro para um projeto React (Vite).

## Estrutura

```
src/
  components/
    GlowBackground.jsx   # blobs de luz ambiente do fundo
    Nav.jsx              # menu de navegação fixo
    Hero.jsx             # seção inicial
    About.jsx            # seção "Quem sou eu"
    Skills.jsx           # seção de habilidades
    Projects.jsx         # seção de projetos
    Contact.jsx          # seção de contato
    Footer.jsx           # rodapé
  hooks/
    useScrollReveal.js   # efeito de revelar seções ao rolar a página
  App.jsx                # junta todos os componentes
  index.css              # todos os estilos (mantidos como no original)
  main.jsx               # ponto de entrada do React
```

## Como rodar localmente

```bash
npm install
npm run dev
```

Abre em `http://localhost:5173`.

## Como gerar a versão de produção

```bash
npm run build
```

Os arquivos finais ficam na pasta `dist/`, prontos pra subir em qualquer serviço de hospedagem (Vercel, Netlify, GitHub Pages, etc).

## Editando conteúdo

Os textos e dados (projetos, skills, links de contato) estão em arrays no topo de cada componente — não precisa mexer no JSX pra trocar textos, é só editar os arrays.
